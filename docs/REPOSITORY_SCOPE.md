# Repository scope

Status: accepted public-source boundary, 2026-08-29.

## Public contents

This repository is the maintained public record for:

- Trail Server architecture and interface exploration;
- the browser interface prototype and clearly labeled demonstration data;
- reproducible Linux host and bounded application deployment work;
- the LUSR/1 server-radio contract and host-simulator implementations;
- public decisions, backlog, status, and sanitized evidence.

The currently published contents remain available under Apache License 2.0.

## Separate production boundary

Future commercial production Trail Server source will be developed and
licensed separately. It is not present in, distributed by, or licensed through
this repository. This separation permits the public prototype and its evidence
to remain reproducible without making future production server source part of
the Apache-licensed boundary.

This repository may continue to receive public documentation corrections,
prototype maintenance, contract clarification, and sanitized evidence. New
production-only implementation must not be copied here.

## Unchanged neighboring boundaries

Trail device firmware, Android software, the Limited Underground website, and
private business planning remain independent repositories or private records.
Public interfaces may be referenced by exact version; source and private
material must not be duplicated across those boundaries.

## Licensing implementation

Commercial license issuance or enforcement is not implemented here. Public
documents must not invent prices, legal terms, availability, or production
readiness. Final production licensing documents require their own review and
do not retroactively change the license already granted for public prototype
versions.
