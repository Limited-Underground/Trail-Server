# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, credential exposure,
privacy leak, or unsafe deployment behavior. Use
[GitHub private vulnerability reporting](https://github.com/Limited-Underground/Trail-Server/security/advisories/new)
and include:

- the affected commit or version;
- the smallest reproducible description;
- expected and observed behavior;
- realistic impact;
- any safe mitigation already tested.

Do not include live credentials, private keys, radio keys, pairing material,
device-specific identifiers, or sensitive field data unless the private report
explicitly requires them.

## Supported versions

This repository is a public engineering prototype and has no supported
production release. Security reports against the current `main` branch are
reviewed on a best-effort basis. Public prototype code must not be used as
emergency, safety, or production infrastructure.

## Disclosure

Please allow time to reproduce, bound, and correct a report before public
disclosure. A fix is not considered accepted until the relevant validation and
publication evidence passes.
