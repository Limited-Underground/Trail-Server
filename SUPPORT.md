# Support

This repository is a non-operational public prototype and reference project. It
does not provide emergency assistance, dispatch, field-service guarantees, or
production support.

Use GitHub Issues for reproducible defects in the public prototype or for
bounded proposals that fit the public scope. Security reports should follow
[SECURITY.md](SECURITY.md) instead of being posted publicly.

Questions about future commercial editions, licensing, or private production
implementation are intentionally outside this repository's public issue scope.
